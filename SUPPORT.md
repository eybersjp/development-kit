# Support

Development Kit is an open-source project maintained on a best-effort basis.

## Before asking for help

1. Read the [README](README.md) and [documentation index](docs/README.md).
2. Confirm you are using the latest release and Node.js 18 or newer.
3. Run the diagnostic gates:

```bash
npm run release:validate
```

4. Search existing issues for the same environment, command, or error.

## Where to ask

- **Reproducible bug:** use the bug-report issue form.
- **Feature or workflow proposal:** use the feature-request issue form.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md), not a public issue.
- **General usage question:** open a GitHub Discussion when discussions are enabled; otherwise open a clearly labelled issue with the environment and attempted steps.

## What to include

Provide the Development Kit version, Node.js version, host agent, operating system, installation mode, exact command, expected behaviour, actual behaviour, and sanitized logs.

Never post credentials, tokens, private keys, customer data, or confidential source code.

## Commercial support

No commercial support or guaranteed response time is currently offered.
