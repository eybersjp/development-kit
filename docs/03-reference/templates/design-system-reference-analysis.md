# design-system-reference-analysis

**Source**: `templates/design-system-reference-analysis.md` · **Lifecycle Stage**: DESIGN

## Purpose

The canonical instruction and template used by Development Kit when analyzing one or more visual references (screenshots, mockups, Figma exports, or existing UI) to infer and generate a complete, 31-section implementation-grade `design.md`.

## Structure

Instructs the analyzing agent to act as a senior Product Designer, Design Systems Architect, and UX Engineer to determine:
*"What reusable design rules would consistently generate interfaces that look like this?"*

Enforces all 31 mandatory sections:
1. Design DNA
2. Reference Analysis
3. Visual Direction
4. Application Shell
5. Layout & Grid
6. Spacing
7. Color System
8. Typography
9. Shape & Radius
10. Borders
11. Shadows & Elevation
12. Iconography
13. Component System
14. Navigation
15. Buttons & Actions
16. Forms
17. Cards
18. Tables & Data Display
19. Feedback & Status
20. Overlays
21. Interaction States
22. Motion
23. Responsive Behaviour
24. Information Density
25. Accessibility
26. Design Tokens
27. Frontend Implementation Rules
28. Visual Invariants
29. Do Not
30. New Screen Generation Rules
31. Design QA Checklist
