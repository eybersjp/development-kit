# idea-brief

**Source**: `templates/idea-brief.md` · **Frontmatter**: `name: idea-brief`

## Intended Lifecycle Stage

UNDERSTAND (idea discovery).

## Intended User / Agent

product-discovery-agent (output of `/dk-idea`).

## Purpose

Documents a refined product or feature idea: problem, users, success criteria, requirements vs preferences, assumptions, constraints, risks, open questions, and deferred ideas.

## Required Sections

Problem · Intended Users · Success Criteria · Requirements (Must) · Preferences (Should) · Assumptions · Constraints · Risks · Open Questions · Future Ideas (Explicitly Deferred)

## Optional Sections

None (all sections are expected).

## How the Template Is Selected

Used when the artifact level is `standard` or `comprehensive` (see `adaptive-artifact-planning`).

## How It Should Be Completed

Every section filled with concrete content. Empty sections are not acceptable — use the idea-challenge skill to force specificity.

## Validation Expectations

- Success criteria must be measurable
- Must/Should/Assumptions/Constraints must be distinct categories
- Deferred ideas explicitly listed (prevents feature creep)
