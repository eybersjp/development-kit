# Development Kit — Documentation System

Welcome to the official documentation for the **Development Kit** framework (`development-kit@0.3.0`).

Development Kit is an opinionated AI software-development methodology and skill collection for Antigravity and OpenCode environments. It installs senior-engineering discipline directly into agent workflows: developing ideas, creating minimal artifacts, breaking work into testable tasks, implementing with fresh sub-agent isolation, verifying rigorously, performing multi-axis reviews, and simplifying relentlessly via the Ponytail simplicity model.
