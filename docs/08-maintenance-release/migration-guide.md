# Migration Guide

This guide provides instructions for upgrading projects between versions of Development Kit.

## Upgrading to v0.3.0

- Run `npx development-kit --project` to update installed skills, commands, and rules.
- Execute `node scripts/sync-plugin.mjs --fix` if managing custom plugins or local framework forks.
