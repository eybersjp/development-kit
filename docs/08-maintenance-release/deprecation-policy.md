# Deprecation Policy

This policy defines how features, commands, or agents are deprecated and removed.

## Timeline

1. **Deprecation Notice**: Feature is marked as deprecated in `CHANGELOG.md` and documentation for at least one minor release cycle.
2. **Warning Log**: Runtime execution emits a deprecation warning linking to migration alternatives.
3. **Removal**: Feature is removed in the next major release.
