# Accessibility Review

Accessibility Review is a specialist review stage triggered for user-facing UI changes.

## Overview

Ensures all visual interfaces satisfy Web Content Accessibility Guidelines (WCAG 2.1 AA) standards, including keyboard navigation, color contrast, ARIA roles, and screen reader support.

## Key Checklist Items

- [ ] Interactive elements are accessible via keyboard navigation.
- [ ] Color contrast ratios satisfy minimum WCAG requirements.
- [ ] Semantic HTML tags (`<main>`, `<nav>`, `<button>`) are used.
- [ ] Focus states are clearly visible.
