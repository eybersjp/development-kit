# Frontmatter & Schema Contracts

## Skill Frontmatter Contract

```yaml
name: <required, kebab-case, equals directory name>
description: >-
  <required, folded scalar — what it does and when to use it>
compatibility: opencode
```

**Validated by**: `validate-skills.mjs` (name + description required).

## Command Frontmatter Contract

```yaml
name: dk-<command>   # required, matches filename
description: >-      # required
  <one sentence: what it does>
```

**Validated by**: `validate-skills.mjs` (frontmatter + `## Purpose`/`## Workflow`).

## Agent Structure Contract

- Top-level `# <Name>` heading
- `## Role` and/or `## Responsibilities` sections

**Validated by**: `validate-skills.mjs` (warning if missing).

## Template Frontmatter Contract

```yaml
name: <artifact-name>
description: Template for <purpose>.
```

**Validated by**: documentation coverage only.

## Evaluation JSON Schema

```json
{
  "skill": "<skill-name>",
  "scenario": "<description>",
  "input": { "...": "..." },
  "expected": { "must_*": true, "must_not": [...], "verdict_contains": "..." }
}
```

**Not machine-validated** — see [known-limitations.md](../11-appendices/known-limitations.md).

## Hook Export Contract

- CommonJS `module.exports`
- Functions: `validateTaskReadiness`, `selectSkillsForTask`, `verifyTaskGates`, `recordTaskCompletion`, `checkCompletionReadiness`
- No load-time side effects

## Manifest Contract (plugin.json)

```json
{
  "name": "development-kit",
  "version": "0.1.0",
  "skills": ["../../../skills/<name>", "..."],
  "agents": ["../../../agents/<name>.md", "..."],
  "hooks": ["../../../hooks/<name>.js", "..."]
}
```

- Generated by `sync-plugin.mjs`; installer rewrites the prefix to `./`.
- References must resolve (checked by `validate-skills.mjs`).

## Documentation Contract (validate-docs)

- Every component type has a reference page under `docs/03-reference/<type>/`.
- No uncompleted placeholder markers, no local `file://` protocol links, no broken relative links.
- Every page reachable from `docs/SUMMARY.md`.

See [running-validation.md](running-validation.md).
