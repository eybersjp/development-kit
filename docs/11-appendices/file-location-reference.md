# File Location Reference

Reference guide for file locations in Development Kit repository and target environments.

## Repository File Layout

- `commands/`: Canonical command definitions.
- `agents/`: Canonical agent definitions.
- `skills/`: Canonical skill packages (`<name>/SKILL.md`).
- `hooks/`: Antigravity lifecycle hooks.
- `templates/`: Documentation templates.
- `evals/`: Evaluation test suites.
- `scripts/`: Maintenance scripts (`install-antigravity.mjs`, `sync-plugin.mjs`, `validate-skills.mjs`, `validate-docs.mjs`).
- `.agents/plugins/development-kit/`: Synchronized plugin mirror directory.
- `docs/`: Comprehensive framework documentation system.
