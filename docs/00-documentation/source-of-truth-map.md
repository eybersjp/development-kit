# Source of Truth Map

## Canonical Source vs. Mirrored Locations

The repository maintains canonical source files at the project root and mirrored/generated plugin manifests inside `.agents/plugins/development-kit/`.

| Component Type | Canonical Location | Mirrored Location | Synchronisation Mechanism | Edit Rule |
| :--- | :--- | :--- | :--- | :--- |
| **Skills** | `skills/<skill_name>/SKILL.md` | Referenced in `.agents/plugins/development-kit/plugin.json` | `node scripts/sync-plugin.mjs` | **Edit Canonical Only** |
| **Agents** | `agents/<agent_name>.md` | Referenced in `.agents/plugins/development-kit/plugin.json` | `node scripts/sync-plugin.mjs` | **Edit Canonical Only** |
| **Commands** | `commands/<command_name>.md` | Mirrored in `.agents/plugins/development-kit/commands/` | `node scripts/install-antigravity.mjs` / manual copy | **Edit Canonical Only** |
| **Hooks** | `hooks/<hook_name>.js` | Mirrored in `.agents/plugins/development-kit/hooks/` | `node scripts/install-antigravity.mjs` / manual copy | **Edit Canonical Only** |
| **Plugin Manifest** | `.agents/plugins/development-kit/plugin.json` | N/A (Generated target) | `node scripts/sync-plugin.mjs --fix` | **Generated by Script** |
| **Rules** | `AGENTS.md` | Root & target installation directories | `node scripts/install-antigravity.mjs` | **Edit Canonical Only** |

## Synchronisation Rules
1. Never edit files in `.agents/plugins/development-kit/` directly unless updating plugin manifest rules.
2. Run `npm run doctor` to check for drift between `skills/`, `agents/`, `hooks/` and `plugin.json`.
3. Run `node scripts/sync-plugin.mjs --fix` after adding or removing skills, agents, or hooks to regenerate `plugin.json`.
