# Review Guidelines

Guidelines for reviewers evaluating PRs in the Development Kit repository.

## Two-Stage PR Review

1. **Specification Compliance**: Verify the PR satisfies the issue/specification requirements.
2. **Code Quality**: Evaluate correctness, maintainability, simplicity, and test coverage.
