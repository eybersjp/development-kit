# Documentation Contributions

How to contribute to Development Kit's comprehensive documentation system.

## Guidelines

- All documentation must be written in GitHub Flavored Markdown.
- No local `file://` protocol URLs are permitted in doc pages.
- Every new page must be registered in `docs/SUMMARY.md`.
- Run `npm run docs:validate` to check for broken links and coverage errors.
