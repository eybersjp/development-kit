# Contribution Overview

Thank you for contributing to Development Kit! This guide outlines how to contribute code, skills, agents, or documentation.

## Core Rules

1. **Specification First**: Non-trivial changes require a specification before implementation.
2. **Reuse Before Creating**: Check existing skills and utilities before introducing new ones.
3. **Always Validate**: Every contribution must pass `npm run validate` and `npm run docs:validate`.
