# Maintainer Responsibilities

Responsibilities and code of conduct for Development Kit core maintainers.

## Key Duties

- Review incoming PRs according to [Review Guidelines](review-guidelines.md).
- Enforce the canonical source vs plugin mirror invariant (`npm run doctor`).
- Maintain documentation quality and link integrity (`npm run docs:validate`).
- Enforce security, trust boundary, and release guidelines.
