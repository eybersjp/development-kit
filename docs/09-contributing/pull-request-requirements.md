# Pull Request Requirements

Requirements for submitting a Pull Request to Development Kit.

## Checklist

- [ ] PR description clearly explains the background, change, and verification steps.
- [ ] Canonical files and mirrored plugin files are in sync (`npm run doctor`).
- [ ] `npm run validate` passes without errors.
- [ ] `npm run docs:validate` passes without errors.
- [ ] Documentation updated for any new command, agent, or skill.
