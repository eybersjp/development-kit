# Evaluation Contributions

How to add or update evaluation suites in `evals/`.

## Structure

Each evaluation suite lives in `evals/<skill-name>/` and contains a JSON file defining evaluation scenarios, prompts, and assertion criteria.

## Verification

When adding an evaluation, add a corresponding reference page in `docs/03-reference/evaluations/<skill-name>.md` and register it in `docs/SUMMARY.md`.
