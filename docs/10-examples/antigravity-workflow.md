# Antigravity Workflow

Demonstrates how Development Kit integrates with the Google Antigravity environment.

## Integration Highlights

- Automatic session initialization via `hooks/session-start.js`.
- Rules loaded automatically via `AGENTS.md` and `rules/`.
- Isolated sub-agent spawning via native subagent tool interfaces.
