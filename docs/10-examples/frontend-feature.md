# Frontend Feature

Walkthrough of building a user interface feature using the `frontend-implementer` sub-agent.

## Key Phases

- **User Flow & Design Direction**: `/dk-design` generates component layout, state models, and design tokens.
- **Implementation**: `frontend-implementer` writes HTML/CSS/JS components without using placeholder data.
- **Runtime Verification**: `browser-runtime-verification` checks DOM behavior, console logs, and accessibility.
- **Reviews**: Stage 1 Spec Compliance → Stage 2 Code Quality → Accessibility & Design Quality Reviews.
