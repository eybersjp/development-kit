# Release Preparation

Walkthrough of preparing a release using `/dk-ship`.

## Steps

1. Verify task completion gates.
2. Run automated validation: `npm run validate && npm run doctor && npm run docs:validate`.
3. Check version numbers across manifests.
4. Prepare clean release commit and PR summary.
