# New Project End-to-End

Walkthrough of building a brand-new project from scratch using the full Development Kit lifecycle.

## Step-by-Step Flow

1. **Initialize Project**: Run `git init` and `npx development-kit --project`.
2. **Idea Discovery**: Run `/dk-idea` to refine the concept and define project scope.
3. **Specification**: Run `/dk-spec` to generate feature specification and acceptance criteria.
4. **Design**: Run `/dk-design` to produce technical architecture and component contracts.
5. **Task Decomposition**: Run `/dk-tasks` to create atomic, risk-ordered tasks.
6. **Automated Implementation**: Run `/dk-build-auto` to execute each task through full review gates.
7. **Verification & Review**: Run `/dk-review` and `/dk-simplify`.
8. **Shipping**: Run `/dk-ship` to verify release readiness.
