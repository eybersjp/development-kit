# OpenCode Workflow

Demonstrates how Development Kit operates inside the OpenCode AI environment.

## Integration Highlights

- Manifest registration in `opencode.json`.
- Skill definitions auto-discovered from `skills/`.
- Standard agent prompts loaded via `AGENTS.md`.
