# Existing Project Feature

Walkthrough of adding a new feature to an existing codebase.

## Workflow

1. **Add Rules**: Ensure `AGENTS.md` is in the project root.
2. **Inspect Context**: The `repository-scout-agent` analyzes existing architecture and utility functions.
3. **Spec & Design**: Execute `/dk-spec` and `/dk-design` prioritizing reuse of existing components.
4. **Build Task**: Execute `/dk-build` for each task slice.
5. **Review & Simplify**: Execute `/dk-review` then `/dk-simplify`.
