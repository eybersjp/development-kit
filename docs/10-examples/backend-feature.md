# Backend Feature

Walkthrough of building a backend service or API endpoint using `backend-implementer`.

## Key Phases

- **API Contract**: `/dk-design` defines request/response types, error codes, and endpoint contracts.
- **TDD Implementation**: Unit tests written for service handlers before logic implementation.
- **Error Handling**: Explicit exception handling and input validation.
- **Review**: Specification compliance and code quality review.
