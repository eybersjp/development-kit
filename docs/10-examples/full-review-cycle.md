# Full Review Cycle

Step-by-step example of running the multi-axis review cycle with `/dk-review`.

## Review Order

1. **Stage 1: Specification Compliance**: Checks if implementation meets all acceptance criteria.
2. **Stage 2: Code Quality**: Assesses correctness, readability, error handling, performance.
3. **Specialist Reviews**: Executes security, accessibility, or design reviews if triggered.
