# Database Change

Walkthrough of executing schema migrations and data model modifications using `database-implementer`.

## Key Phases

- **Data Model Design**: `/dk-design` specifies database schema, constraints, indexes, and migration scripts.
- **Migration Execution**: Migration script created and tested against local test database.
- **Data Integrity Verification**: Verification rules ensure zero data loss or migration deadlocks.
